# Автолига · Демонстрация тест-драйва

[Открыть страницу](https://siberiabear38.github.io/avtoliga-test-drive-demo/)

Демонстрационная версия для согласования. Форма проверяет имя, телефон и согласие, но **не отправляет заявки**.

Маска сохраняет префикс +7 при вводе, вставке и удалении номера. На компьютере страница остаётся мобильной по ширине и полностью прокручивается.

На GitHub Pages размещены только статические файлы. Почтовый обработчик и настройки получателя в эту публикацию не входят.
